# Humblepaper

We build [Leela](https://leela.works), a contract negotiation agent that works over email, and we maintain [The Contract Room](https://thecontractroom.com), an open reference for commercial deal-making.

- [contract-room-ontology](https://github.com/HumblePaper/contract-room-ontology): the reference source, an open and cited ontology (CC BY 4.0). Pull requests welcome; merges go live on the site.
- [awesome-contract-negotiation](https://github.com/HumblePaper/awesome-contract-negotiation): forms, playbooks, data, tools and communities for people who negotiate contracts.
- [awesome-ai-native-law-firms](https://github.com/HumblePaper/awesome-ai-native-law-firms): law firms built with AI as the way the work gets done, grouped by how they are built.
- [awesome-people-in-legal-tech](https://github.com/HumblePaper/awesome-people-in-legal-tech): the people building and shaping legal technology, cross-referenced with the two lists above.
- [awesome-legal-ai-benchmarks](https://github.com/HumblePaper/awesome-legal-ai-benchmarks): benchmarks, leaderboards, rubrics and evaluation datasets for AI in legal work.
