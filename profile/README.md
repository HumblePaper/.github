# Humblepaper

Humblepaper builds [Leela](https://leela.works), a contract negotiation agent that works over email, and maintains [The Contract Room](https://thecontractroom.com), an open reference for commercial deal-making. These repositories hold the reference source and the lists we keep alongside it.

- [contract-room-ontology](https://github.com/HumblePaper/contract-room-ontology): the reference source, an open and cited ontology (CC BY 4.0). Pull requests welcome. Merges go live on the site.
- [awesome-contract-negotiation](https://github.com/HumblePaper/awesome-contract-negotiation): the forms, playbooks, data, tools and communities that are useful to anyone who negotiates commercial contracts.
- [awesome-ai-native-law-firms](https://github.com/HumblePaper/awesome-ai-native-law-firms): law firms built around AI from the start, grouped by how each one is put together.
- [awesome-people-in-legal-tech](https://github.com/HumblePaper/awesome-people-in-legal-tech): the people building and shaping legal technology, cross-referenced with the lists above and below.
- [awesome-legal-ai-benchmarks](https://github.com/HumblePaper/awesome-legal-ai-benchmarks): the benchmarks, leaderboards, rubrics and datasets that measure how well AI does legal work.
